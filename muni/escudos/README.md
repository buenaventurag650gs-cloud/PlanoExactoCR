# Escudos municipales

Poné acá el escudo de cada municipalidad como PNG, con el nombre del cantón en
minúsculas, sin tildes y con guiones en vez de espacios:

- `acosta.png`
- `montes-de-oca.png`
- `san-jose.png`

Cuando elegís un cantón en el tablero, el sistema busca `escudos/<canton>.png` y,
si existe, lo pone solo en el cajetín de las láminas y en la vista de pantalla.
Si no existe, podés subir un logo a mano desde el tablero.

Formato recomendado: PNG con fondo transparente, lado mayor ~300 px.
